# SearchMate
SearchMate is a simple search system built using the Trie data structure.  
It allows users to explore Data Structures topics through search and autocomplete features.

## Features
- 📂 View all topics with descriptions  
- 🔎 Search topics using keywords  
- ⚡ Autocomplete suggestions using Trie  
- 🧠 Case-insensitive matching  
- 📊 Menu-driven interface  

## 🧱 Technologies Used
- C++
- File Handling
- Trie Data Structure
- String Processing

## 📁 Dataset Format
Each topic is stored in the following format:
Topic | Short Description | Detailed Description | Image | Keywords

Example:
AVL Tree | Self-balancing BST | Detailed explanation... | image.png | avl tree balanced bst
